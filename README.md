# 💌 Undangan Digital

Platform undangan digital pernikahan — self-serve, WhatsApp-first.

Buat undangan pernikahan profesional dalam 10 menit, tanpa bantuan CS.

## Tech Stack

| Layer | Tech |
|---|---|
| Frontend | Next.js + Tailwind CSS + Framer Motion |
| Backend | Golang + Gin + GORM |
| Database | PostgreSQL (Supabase) |
| Auth | Supabase Auth + JWT |
| Storage | Supabase Storage + Cloudflare R2 |
| Hosting | Vercel (FE) + Railway/Fly.io (BE) |

## Project Structure

```
/
├── frontend/     # Next.js app
├── backend/      # Golang + Gin API
└── docs/         # Documentation & PRD
```

## Roadmap

- **Phase 1 (MVP):** Template picker, RSVP, share link, guest dashboard, amplop digital
- **Phase 2 (Growth):** WA notification, wish wall, analytics, reminder
- **Phase 3 (Scale):** Custom domain, white-label B2B, template adat daerah
